# Navigation models

`safepaths-sedan-v1.glb` is an original procedural SafePaths model, generated by
`scripts/navigation/build_car.py`. No third-party meshes, textures, brand marks
or network resources are included. Regenerate from the repository root:

```powershell
python scripts/navigation/build_car.py
```

The model uses glTF 2.0: Y up, -Z forward, metres. It is 4.18 m long,
2.02 m wide and 1.48 m high; 506 triangles, seven solid-color materials.
The application uses viewport scaling to keep it about 38 screen pixels long.
**Disabled in all normal builds after a native Mapbox SIGSEGV on the Pixel_9
x86_64 emulator on November 2, 2026.** All modes use their own 2D markers.
The asset and generator remain for isolated diagnosis; they are not a completed
or device-approved feature. Dart exception handlers cannot recover a native
process crash. Do not re-enable based only on unit tests or a preview render.

Native checks still required: axis/direction on a known north/east road,
legibility in light/dark maps at different camera angles, style reload, reroute,
missing-model fallback and Android 11 performance. Static/model tests do not
prove native GPU rendering or device performance.
