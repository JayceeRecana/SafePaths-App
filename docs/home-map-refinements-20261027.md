# Home map and road-details refinement — 27 October 2026

The resident home controls now use the existing AppPalette, Manrope headings and Inter body text in both themes. Opaque theme surfaces replace the white translucent header, legend and selected-road card that made dark-mode text unreadable. The fullscreen map's search surface and text also follow the theme. The native Mapbox texture-view rendering mode is retained.

Search remains available as **Find a road or place**, alongside the existing weather-details button. The road-list shortcut moves from the Settings row into the new **Road conditions** sheet as **Browse roads**. The sheet explains passable, partial, not passable and needs confirmation, using solid/dashed markers and complete labels. It is scrollable at large text sizes.

The home screen no longer selects the first database road on startup. A preview appears after an intentional street tap or road search; its close button clears selection. Starting a new search clears the old selection. The preview prioritizes the road name and condition, followed by the recorded update age and any actual admin note. Empty notes no longer produce the unsupported claim No recent reports. Report submission receives the selected road as a prefill without automatically requesting urgent assistance.

The alert banner now occupies its own space above Map/Planner rather than covering the map header, and its severity colors use matching theme foreground/container pairs. Map controls have labelled touch targets and adapt to smaller viewports. The map loading/error/retry banner is placed in the visible home overlay. Its status object has explicit ownership; other AppMap callers keep their existing internal banner by default.

Locate uses the shared freshness/accuracy checks instead of immediately centering on an old cached fix. Repeated requests are blocked while locating. Camera-dependent actions check map readiness, including after a retry. Closing search invalidates pending network responses so an old response cannot reopen or move the current search. The existing search API area limits and timeout remain.

Imported OSM roads with no verified condition update now use the existing uncertainty-advisory path. Missing road status no longer defaults to passable. These roads appear as dashed amber / Needs confirmation, consistently in the map, selected preview, road list and details. No stored road status is rewritten by this presentation change. An administrator's verified update can clear uncertainty. Recorded closures remain blocking conditions.

Uncertainty is not allowed to erase a critical predicted risk: a critical estimate keeps its risk totals and critical routing classification, while remaining distinct from a recorded physical closure. Regression checks cover unreviewed roads, unknown status, verified updates, critical estimates and confirmed closures. Prediction calibration, field validation and beneficiary approval are not established by these checks.

Road details opens at 60% height, can shrink to 40% or expand to 95%, and retains a visible close/resize bar while the content scrolls. The bar supports dragging and tapping to expand/collapse. Reduced-motion users resize without animation. The previous report/admin-update hierarchy and full content remain available. Imported roads are described as awaiting verification rather than incorrectly claiming a prior confirmation.
